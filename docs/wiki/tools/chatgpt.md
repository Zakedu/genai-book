## 모델 라인업

### GPT-5 (기본 모델)

2025년 2월부터 모든 ChatGPT 사용자의 기본 모델로 설정되었습니다.

**특징**:

- 텍스트, 이미지, 오디오, 비디오 네이티브 멀티모달 입출력
- 128K 컨텍스트 윈도우
- 창의적 글쓰기와 자연스러운 대화에 강점
- 환각 감소 및 향상된 추론 능력
- Advanced Voice Mode로 실시간 음성 대화 (감정 표현, 노래, 다국어 동시통역)
- 현재 Plus/Pro 사용자의 표준 모델

### GPT-5.2 계열 (변형 모델)

2026년 2월 기준 활발히 사용되는 GPT-5의 변형들입니다.

**특징**:

- **GPT-5.2 Instant**: 빠른 응답, 경제적 선택지
- **GPT-5.2 Thinking**: 추론 강화 (o3 기반 추론 엔진 통합)
- **GPT-5.2 Pro**: 최고 품질, 향상된 능력
- 모든 변형이 멀티모달 지원

### o1 · o3 추론 모델

복잡한 문제를 단계별로 사고하는 추론 특화 모델 시리즈입니다.

| 모델 | 출시일 | 특징 |
|------|--------|------|
| **o4** | 2026년 2월 | 차세대 추론 모델, 수학·과학·코딩에서 인간 전문가 수준 |
| **o4-mini** | 2025년 말 | 경량 추론, 빠른 응답, 코딩에 최적 |
| **o4 pro mode** | 2026년 2월 | Pro 전용, 강화된 연산으로 최고 정확도 |
| **o3-deep-research** | 2025년 중 | 연구 전문, 심층 분석에 특화 |

**추론 모델의 특징**:

- Chain of Thought: 답변 전 단계별 사고 과정 수행
- 수학 올림피아드, 박사 수준 과학 문제에서 인간 전문가급 성능
- 코딩 대회(경쟁 프로그래밍) 상위권 달성
- 응답 시간이 길지만 정확도가 월등히 높음

### GPT-5.2 계열 (Free 기본 모델)

2026년 2월부터 Free 플랜의 기본 모델로 설정되었습니다.

**특징**:

- 빠른 응답 속도, 저렴한 비용
- 128K 컨텍스트 윈도우
- Free 플랜의 기본 모델
- 일상적인 대부분의 작업에 충분

## 핵심 기능

### 1. Deep Research

2025년 2월 출시된 자율 심층 조사 기능입니다.

**특징**:

- o3 기반으로 수십 개 웹 소스를 자동 탐색·분석
- 5~30분간 독립적으로 리서치 수행
- 출처가 명시된 종합 보고서 자동 생성
- 학술 연구, 시장 분석, 기술 조사에 적합

**예시 프롬프트**:

```
"2024년 글로벌 AI 반도체 시장 동향을 심층 조사해줘.
주요 기업(NVIDIA, AMD, Intel), 매출 규모, 기술 트렌드,
2025년 전망을 포함한 보고서를 작성해줘."
```

!!! tip "사용량"
    Pro 플랜은 무제한, Plus 플랜은 월 10회 제공됩니다.

### 2. Canvas

문서와 코드를 나란히 편집하는 협업 인터페이스입니다.

**특징**:

- 대화창 옆에 별도 편집 캔버스 제공
- 글쓰기: 길이 조절, 톤 변경, 문단별 피드백, 이모지 추가
- 코딩: 버그 수정, 코드 리뷰, 로그 삽입, 언어 변환
- 버전 히스토리로 이전 상태 복원 가능
- Python 코드 직접 실행 지원

### 3. Custom GPTs

특정 목적에 맞는 맞춤형 AI 에이전트를 코딩 없이 만들 수 있습니다.

**활용 예시**:

- 회사 내부 규정 기반 Q&A 봇
- 특정 분야 전문 튜터
- 업무 자동화 워크플로우
- 외부 API 연동 (Actions 기능)

**GPT Store**: 사용자가 만든 GPTs를 공유·검색할 수 있는 마켓플레이스입니다. 교육, 글쓰기, 프로그래밍 등 카테고리별로 탐색 가능합니다.

### 4. Projects

대화를 프로젝트 단위로 정리하는 기능입니다 (2025년 1월 출시).

**특징**:

- 관련 대화를 하나의 프로젝트로 묶어 관리
- 프로젝트별 파일 업로드 및 지침(Instructions) 설정
- Custom GPTs를 프로젝트에 연결 가능
- 업무·학습·개인 프로젝트 별도 구성

### 5. Memory

대화 간 맥락을 기억하는 장기 기억 기능입니다.

**특징**:

- 사용자 선호도, 작업 스타일, 배경 정보를 자동 학습
- 명시적으로 "이것을 기억해줘"라고 지시 가능
- 설정에서 기억 항목 확인·삭제 가능
- 전체 Memory를 끌 수도 있음

```
활용 예시:
"나는 Python 개발자이고, FastAPI를 주로 사용해. 기억해줘."
→ 이후 코딩 질문 시 자동으로 Python/FastAPI 기반 답변
```

### 6. Operator

2025년 1월 출시된 AI 에이전트로, 웹 브라우저를 직접 조작합니다.

**특징**:

- 실제 웹사이트를 자율적으로 탐색·클릭·입력
- 쇼핑, 예약, 양식 작성 등 실제 작업 수행
- 중요한 결정(결제 등)에서는 사용자 확인 요청
- Pro 플랜 전용, 미국에서 우선 제공

**활용 예시**:

- 온라인 식료품 주문
- 레스토랑 예약
- 항공권·호텔 검색 및 비교
- 반복적인 웹 양식 작성

### 7. 이미지 생성

두 가지 방식의 이미지 생성을 지원합니다.

=== "네이티브 이미지 생성 (GPT-5)"
    GPT-5에 내장된 이미지 생성 기능입니다. 대화 맥락을 이해하고 텍스트가 포함된 정교한 이미지를 생성합니다.

    - 텍스트 렌더링 정확도 대폭 향상
    - 대화 흐름에 맞는 맥락 인식 생성
    - 업로드 이미지 편집·변환 가능
    - 인포그래픽, 로고, 포스터 등 텍스트 포함 이미지에 강점

=== "DALL-E 3"
    기존 이미지 생성 모델로, 예술적 스타일의 이미지에 적합합니다.

    - 다양한 아트 스타일 지원
    - 고해상도 이미지 생성
    - Plus 이상 플랜에서 사용 가능

```
프롬프트 예시:
"한국 전통 한옥과 현대 빌딩이 어우러진 서울 야경,
네온사인이 비에 반사되는 모습, 시네마틱 스타일"
```

### 8. Sora (동영상 생성)

2024년 12월 출시된 텍스트-투-비디오 생성 모델입니다.

**특징**:

- 텍스트 설명으로 최대 20초 영상 생성
- 1080p 해상도 지원
- 기존 이미지/영상을 확장·편집 가능
- Storyboard 기능으로 장면별 제어

!!! tip "Sora 접근"
    Plus 플랜은 월 제한적 사용, Pro 플랜은 우선 접근 및 확대된 사용량을 제공합니다.

### 9. 고급 데이터 분석 (Advanced Data Analysis)

Python 코드를 실행하여 데이터를 분석합니다.

**가능한 작업**:

- CSV, Excel, JSON 파일 업로드 및 분석
- 차트·그래프 시각화 자동 생성
- 통계 분석, 회귀 분석, 클러스터링
- 데이터 정제·변환·병합

### 10. 웹 검색 (ChatGPT Search)

실시간 웹 검색으로 최신 정보를 제공합니다.

**특징**:

- 대화 중 자동으로 웹 검색 수행
- 출처 링크와 함께 답변 제공
- 날씨, 주가, 스포츠 등 실시간 정보 지원
- Free 플랜에서도 기본 검색 가능

## 사용 팁

### 효과적인 프롬프트 작성

=== "기본 질문"
    ```
    파이썬으로 웹 크롤러 만들어줘
    ```

=== "상세 프롬프트"
    ```
    파이썬으로 웹 크롤러를 만들어주세요.

    요구사항:
    - requests와 BeautifulSoup 라이브러리 사용
    - 뉴스 사이트에서 제목과 링크 추출
    - 결과를 CSV 파일로 저장
    - 에러 처리 포함
    - 주석으로 코드 설명 추가
    ```

=== "추론 모델용"
    ```
    다음 최적화 문제를 풀어주세요.

    물류 창고 3곳에서 고객 10곳으로 배송할 때,
    총 운송 비용을 최소화하는 배분 계획을 구하세요.
    [데이터 첨부]

    단계별로 풀이 과정을 보여주세요.
    ```
