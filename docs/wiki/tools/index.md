## 🛠️ 도구 선택 가이드

### 용도별 추천

=== "일반 대화/글쓰기"

    **1순위**: ChatGPT, Claude
    
    - 자연스러운 대화
    - 다양한 글쓰기 스타일

=== "긴 문서 분석"

    **1순위**: Claude

    - 100만 토큰(1M) 처리 가능
    - 문서 전체 맥락 유지, 여러 권의 책 동시 분석

=== "최신 정보 검색"

    **1순위**: Gemini
    
    - Google 검색 실시간 연동
    - 최신 정보 접근

=== "코딩/개발"

    **1순위**: Claude (Claude Code), ChatGPT (GPT-5.6)

    - 코드 생성 및 디버깅
    - 다양한 언어 지원
