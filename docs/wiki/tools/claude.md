# Claude


Anthropic이 개발한 AI 어시스턴트입니다. Constitutional AI 원칙에 기반한 안전성과 유용성의 균형을 중시하며, **1M 토큰 컨텍스트 윈도우 (GA)**, Artifacts 실시간 생성, Projects, MCP, Computer Use 에이전트 등 강력한 기능을 제공합니다. Opus 4.6, Sonnet 4.6 모두 1M 토큰 GA(General Availability)를 달성하였으며, Claude 4.6 계열이 2026년 최신 모델입니다.

## 핵심 기능

### 1. Projects (프로젝트)

커스텀 지시(Custom Instructions)와 문서 업로드로 맞춤형 작업 환경을 구성합니다.

**특징**:

- 프로젝트별 커스텀 지시 설정으로 응답 스타일·톤·규칙 지정
- PDF, 텍스트, 코드 파일 등 다양한 문서 업로드 (최대 수십 개)
- 업로드된 문서를 컨텍스트로 활용한 정확한 답변
- 팀원과 프로젝트 공유 가능 (Team/Enterprise)

**활용 예시**:

- 회사 매뉴얼 + 브랜드 가이드라인 기반 Q&A 시스템
- 연구 논문 모음을 업로드하여 문헌 분석
- 코드베이스 업로드 후 코드 리뷰·리팩토링
- "항상 한국어로, 존댓말로 답변하세요" 같은 지시 설정

**사용 방법**:

1. 프로젝트 생성 및 이름 설정
2. 커스텀 지시 작성 (선택)
3. 관련 문서 업로드
4. 프로젝트 컨텍스트 기반으로 대화

### 2. Cowork (협업 에이전트)

지속적인 에이전트 스레드(persistent agent thread)를 통해 장기 프로젝트를 관리하는 기능입니다.

**특징**:

- 여러 대화 세션에 걸쳐 작업 맥락을 유지
- 에이전트가 독립적으로 작업을 수행하고 결과를 보고
- 복잡한 프로젝트의 단계별 진행 관리
- Pro 이상 플랜에서 사용 가능

### 3. Artifacts (아티팩트)

코드, 문서, 다이어그램을 실시간으로 생성하고 미리볼 수 있는 인터랙티브 패널입니다.

**생성 가능한 유형**:

| 유형 | 설명 |
|------|------|
| HTML/CSS/JS | 웹페이지 실시간 미리보기 |
| React 컴포넌트 | 인터랙티브 UI 생성 및 실행 |
| SVG 다이어그램 | 벡터 그래픽 생성 |
| Mermaid | 플로우차트, 시퀀스 다이어그램, ER 다이어그램 |
| 마크다운 | 서식 있는 문서 |
| 코드 스니펫 | Python, JavaScript 등 코드 블록 |

**특징**:

- 대화창 옆에 별도 패널로 렌더링
- 생성된 결과물을 즉시 수정·반복 가능
- 공유 링크로 다른 사람에게 전달 가능
- Remix 기능으로 다른 사용자의 Artifact를 복사·수정
- 2026년 3월부터 대화 내에서 직접 **인라인 시각화**가 가능합니다 (아래 상세 참조).

**예시 프롬프트**:

```
React로 할 일 목록 앱을 만들어줘.
- 항목 추가/삭제 기능
- 완료 체크 기능
- 필터(전체/완료/미완료)
- 깔끔한 UI 디자인
```

#### 인라인 시각화 (Inline Visualization)

2026년 3월부터 Claude가 대화 안에서 직접 차트, 다이어그램, 그래프를 생성하는 기능입니다. Artifacts가 별도 사이드 패널에서 결과물을 보여주는 것과 달리, 인라인 시각화는 대화 흐름 안에 시각적 요소를 직접 삽입합니다.

**Artifacts vs 인라인 시각화**:

| 구분 | Artifacts | 인라인 시각화 |
|------|-----------|--------------|
| **표시 위치** | 별도 사이드 패널 | 대화 흐름 내 삽입 |
| **결과물 복잡도** | HTML/React/SVG 등 복잡한 결과물 | 간단한 차트·다이어그램 |
| **버전 관리** | 수정·반복·Remix 가능 | 대화 맥락에 따라 새로 생성 |
| **맥락 유지** | 패널 전환 필요 | 대화 흐름을 끊지 않고 확인 |
| **적합한 용도** | 인터랙티브 앱, 복잡한 다이어그램 | 빠른 데이터 요약, 비교 시각화 |

**지원 시각화 유형**:

| 유형 | 설명 |
|------|------|
| 막대 차트 | 항목별 수치 비교 |
| 파이 차트 | 구성 비율 시각화 |
| 라인 그래프 | 시계열 추이 표현 |
| 플로우차트 | 프로세스·워크플로우 흐름 |
| 다이어그램 | 구조·관계 시각화 |
| 테이블 시각화 | 데이터를 시각적으로 강조한 표 |

**활용 사례**:

- 데이터 분석 결과를 대화 중 즉시 차트로 요약
- 여러 옵션의 장단점을 비교 다이어그램으로 정리
- 프로세스나 절차를 플로우차트로 설명
- 통계 수치를 그래프로 시각화하여 보고

**사용 팁**:

```
"이 데이터를 차트로 보여줘"
"비교 결과를 다이어그램으로 정리해줘"
"월별 추이를 그래프로 그려줘"
"이 프로세스를 플로우차트로 만들어줘"
```

!!! tip "Artifacts와 인라인 시각화 선택 기준"
    복잡한 인터랙티브 결과물이나 코드 실행이 필요하면 Artifacts를, 대화 맥락을 유지하면서 빠르게 데이터를 시각화하고 싶다면 인라인 시각화를 활용하세요.

### 4. Analysis Tool (데이터 분석)

Python 코드를 실행하여 데이터를 분석하고 시각화합니다.

**가능한 작업**:

- CSV, Excel, JSON 파일 업로드 및 분석
- 차트·그래프 시각화 자동 생성 (Matplotlib, Plotly 등)
- 통계 분석, 회귀 분석, 클러스터링
- 데이터 정제·변환·병합
- 수학적 계산 및 시뮬레이션

**예시 프롬프트**:

```
이 매출 데이터(CSV)를 분석해줘.
- 월별 매출 추이 그래프
- 상위 10개 제품 매출 비교
- 전년 대비 성장률 계산
- 이상치(outlier) 탐지
```

!!! tip "Analysis Tool 접근"
    Pro 이상 플랜에서 사용 가능합니다. JavaScript 실행도 지원됩니다.

### 5. Vision (이미지·PDF 분석)

이미지와 PDF를 직접 인식하고 분석합니다.

**지원 형식**:

- 이미지: JPEG, PNG, GIF, WebP
- 문서: PDF (수백 페이지도 처리 가능)

**활용 예시**:

- 차트·그래프 이미지를 읽고 데이터 해석
- 손글씨·스크린샷 텍스트 추출 (OCR)
- UI 스크린샷 분석 및 코드 변환
- 학술 논문 PDF 전체 요약
- 건축 도면·다이어그램 해석

**예시 프롬프트**:

```
[이미지 첨부]
이 대시보드 스크린샷을 분석하고,
주요 지표의 의미와 개선 포인트를 설명해줘.
```

### 6. Computer Use (베타)

AI가 컴퓨터 화면을 직접 보고 마우스·키보드를 조작하는 에이전트 기능입니다.

**특징**:

- 스크린샷을 인식하여 화면 상태 파악
- 마우스 클릭, 키보드 입력, 스크롤 등 직접 조작
- 웹 브라우징, 앱 사용, 폼 작성 등 실제 작업 수행
- API를 통해 개발자가 자동화 워크플로우 구축 가능

**활용 예시**:

- 반복적인 웹 양식 입력 자동화
- 소프트웨어 테스트 자동화
- 데이터 입력 및 수집 워크플로우
- 레거시 시스템과의 연동

!!! warning "베타 기능"
    Computer Use는 현재 베타 단계로 API를 통해 제공됩니다. 정확도와 속도가 계속 개선되고 있으며, 민감한 작업에는 주의가 필요합니다.

### 7. MCP (Model Context Protocol)

외부 도구 및 데이터 소스와 Claude를 연동하는 오픈 표준 프로토콜입니다.

**특징**:

- Anthropic이 주도하고 오픈소스로 공개한 표준 규격
- 다양한 외부 서비스(GitHub, Slack, 데이터베이스 등)와 양방향 연동
- 로컬 파일 시스템, API, 데이터베이스 등에 접근 가능
- Claude Desktop 앱에서 MCP 서버를 직접 연결하여 사용

**지원 연동 예시**:

| 카테고리 | 연동 서비스 |
|----------|-----------|
| 개발 도구 | GitHub, GitLab, Linear |
| 데이터베이스 | PostgreSQL, SQLite, MongoDB |
| 생산성 | Slack, Google Drive, Notion |
| 파일 시스템 | 로컬 폴더, 클라우드 스토리지 |

**활용 시나리오**:

```
[MCP로 GitHub 연동 후]
"내 레포지토리에서 최근 PR을 리뷰하고,
코드 품질 이슈를 정리해줘."
```

!!! tip "MCP 오픈소스"
    MCP 사양과 SDK는 GitHub에서 오픈소스로 공개되어 있으며, 누구나 MCP 서버를 개발하여 Claude와 연동할 수 있습니다.

### 8. Claude Code (개발자 도구)

터미널 기반의 AI 코딩 에이전트로, 개발 워크플로우를 강력하게 지원합니다.

**특징**:

- Opus 4.6을 기본 모델로 사용
- 음성 모드(`/voice`)로 음성 지시 가능
- 반복 실행(`/loop`)으로 자동화된 코드 수정 반복
- MCP 서버 연동으로 외부 도구 통합
- 최신 버전 v2.1.76

### 9. 긴 문서 처리

1M 토큰 컨텍스트 윈도우로 장문 분석에 강점이 있습니다.

**활용 예시**:

- 100페이지 이상 논문 요약
- 계약서 전문 분석 및 리스크 식별
- 코드베이스 전체 리뷰 및 아키텍처 분석
- 긴 회의 녹취록 정리
- 여러 권의 책을 한 번에 업로드하여 비교 분석

### 10. Constitutional AI

Anthropic의 AI 안전성 철학인 Constitutional AI에 기반한 응답을 생성합니다.

**핵심 원칙**:

- **무해성(Harmlessness)**: 유해한 콘텐츠 생성을 거부하되, 유용성을 최대한 유지
- **정직성(Honesty)**: 불확실한 정보에 솔직하게 "모른다"고 답변
- **도움됨(Helpfulness)**: 사용자의 의도를 파악하여 최대한 유용한 답변 제공

**특징**:

- 인간 피드백(RLHF) + AI 자체 평가의 결합으로 학습
- 명시적 원칙(헌법)에 따라 스스로의 응답을 평가·수정
- 편향 최소화 및 다양한 관점 제시 노력
- 명확한 거부 사유 설명 (단순 차단이 아닌 이유 제시)

| 일상 대화·간단한 질문 | Claude Haiku 4.5 | 빠르고 효율적 |
| 글쓰기·분석·코딩 | Claude Sonnet 4.6 | 속도와 품질의 최적 균형 |
| 복잡한 추론·연구 | Claude Opus 4.6 | 최고 수준의 사고력 |
| 대량 처리·자동화 | Claude Haiku 4.5 | 빠른 처리, 낮은 비용 |

### Claude의 강점 활용

| 작업 유형 | 추천 프롬프트 패턴 |
|----------|-------------------|
| 글쓰기 | "~한 톤으로, ~한 독자를 대상으로 작성해줘" |
| 분석 | "여러 관점에서 분석하고, 장단점을 비교해줘" |
| 코딩 | "코드와 함께 설명을 주석으로 추가해줘" |
| 번역 | "자연스러운 한국어로, 의역보다 직역 위주로" |
| Vision | "[이미지 첨부] 이 화면을 분석하고 코드로 구현해줘" |
| 데이터 | "이 CSV를 분석하고 인사이트를 시각화해줘" |

### 멀티턴 대화 활용

Claude는 긴 대화 맥락을 잘 유지합니다.

```
1차: "마케팅 전략 보고서를 작성하려고 해"
2차: "타겟 고객층은 20-30대 직장인이야"
3차: "SNS 마케팅에 집중하고 싶어"
4차: "이제 보고서 초안을 작성해줘"
```
