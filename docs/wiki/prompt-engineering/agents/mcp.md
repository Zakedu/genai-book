# MCP (Model Context Protocol)

## 개요

**MCP(Model Context Protocol)**는 AI 모델이 외부 도구·데이터·서비스와 연결되는 방식을 표준화한 개방형 프로토콜입니다. 2024년 11월 Anthropic이 공개한 이후 OpenAI, Google 등 주요 벤더가 잇달아 지원을 발표하면서, 2026년 현재 에이전트 생태계의 사실상 표준 연결 규격으로 자리 잡았습니다.

!!! abstract "학습 목표"
    - MCP가 해결하는 문제(N×M 통합 문제)를 설명할 수 있다
    - 호스트·클라이언트·서버 구조와 세 가지 제공 기능(도구·리소스·프롬프트)을 구분할 수 있다
    - MCP 도입 시 반드시 검토해야 할 보안 리스크를 열거할 수 있다

## 왜 MCP가 필요한가 — N×M 통합 문제

MCP 이전에는 AI 애플리케이션마다, 그리고 연결할 서비스마다 **전용 통합 코드를 따로** 만들어야 했습니다. 앱이 N개, 도구가 M개면 통합도 N×M개가 필요한 구조였죠.

MCP는 이것을 **"AI 세계의 USB-C"**처럼 표준화합니다. 도구 제공자는 MCP 서버 하나만 만들면 되고, AI 앱은 MCP 클라이언트 하나만 구현하면 어떤 MCP 서버와도 연결됩니다.

| 구분 | MCP 이전 | MCP 이후 |
|------|---------|---------|
| 통합 개수 | N(앱) × M(도구) | N + M |
| 도구 추가 | 앱마다 개별 개발 | MCP 서버 1개 배포 |
| 유지보수 | 통합별 개별 대응 | 프로토콜 표준 준수 |

## 구조: 호스트 · 클라이언트 · 서버

```
[호스트 앱]  ←  Claude Desktop, IDE, 챗봇 등 사용자가 쓰는 프로그램
    └─ [MCP 클라이언트]  ←  서버와 1:1 연결을 관리
            └─ [MCP 서버]  ←  도구·데이터를 제공 (파일시스템, DB, 웹검색, 사내 API…)
```

- **호스트(Host)**: 사용자가 직접 사용하는 AI 애플리케이션
- **클라이언트(Client)**: 호스트 안에서 각 서버와의 연결을 담당
- **서버(Server)**: 실제 기능을 제공하는 경량 프로그램

전송 방식(트랜스포트)은 로컬 프로세스 간 통신인 **STDIO**와 원격 연결용 **HTTP 스트리밍** 두 가지가 주로 쓰입니다.

## MCP 서버가 제공하는 세 가지

1. **도구(Tools)** — 모델이 호출할 수 있는 실행 가능한 기능 (예: 검색 실행, 메일 전송, DB 질의)
2. **리소스(Resources)** — 모델이 읽을 수 있는 데이터 (예: 파일 내용, 문서, 스키마)
3. **프롬프트(Prompts)** — 서버가 제공하는 재사용 가능한 프롬프트 템플릿

!!! example "실무 예시"
    회사 위키를 MCP 서버로 노출하면, 사내 어떤 AI 도구든 "위키에서 휴가 규정 찾아줘" 같은 요청을 처리할 수 있게 됩니다. 위키 쪽 통합 코드는 하나면 충분합니다.

## 보안: 편리함의 대가

MCP는 에이전트에게 **실제 실행 권한**을 연결하는 통로이므로, 보안 검토 없이 도입하면 위험이 그대로 전이됩니다.

!!! warning "툴 포이즈닝 (Tool Poisoning)"
    MCP 서버가 제공하는 도구의 **메타데이터(설명문) 안에 악성 지시문을 숨겨** 배포하는 공격입니다. 모델은 도구 설명을 신뢰해 읽기 때문에, 오염된 설명이 곧 주입된 명령처럼 작동할 수 있습니다. 2026년 4월에는 보안업체 OX Security가 MCP 공식 SDK의 STDIO 트랜스포트 처리 방식을 설계 결함으로 지목하고, 다운로드 기준 대규모 공급망이 영향권에 있다고 공개해 생태계 차원의 점검이 이루어졌습니다.

**도입 시 최소 점검 목록:**

- [ ] 서버 출처 검증 — 공식/사내 서버만 허용, 서명·버전 고정
- [ ] 권한 최소화 — 읽기 전용으로 시작, 실행 권한은 명시적 승인
- [ ] 도구 설명 감사 — 설치 전 메타데이터에 이상 지시문이 없는지 확인
- [ ] 민감 작업 인간 승인 — 결제·삭제·전송은 사람 확인 단계 유지

→ 에이전트 전반의 보안 위협은 [AI 에이전트 보안](../../security/agent-security.md) 문서에서 자세히 다룹니다.

## 시험 대비 핵심 정리

- MCP = AI와 도구·데이터를 잇는 **개방형 표준 프로토콜** (N×M → N+M)
- 구조는 **호스트 → 클라이언트 → 서버**, 제공 기능은 **도구·리소스·프롬프트** 3종
- 주요 자격시험(클라우드 벤더 AI 자격 등)이 MCP를 에이전트 오케스트레이션의 선수 지식으로 편입하는 추세
- 보안 필수 키워드: **툴 포이즈닝**, 권한 최소화, 공급망 검증
