# LLM을 이용한 텍스트 요약

텍스트 요약은 대량의 정보를 빠르게 파악해야 하는 현대 업무에서 필수적인 기술입니다. 이 섹션에서는 추출 요약, 추상 요약, 다양한 요약 형식을 다룹니다.

## 핵심 개념

### 1. 텍스트 요약의 두 가지 유형

#### 추출 요약 (Extractive Summarization)
원문의 핵심 문장을 그대로 추출하여 연결합니다.

**장점**: 정확도 높음, 원문 기반 정보
**단점**: 부자연스러운 문장 연결 가능

#### 추상 요약 (Abstractive Summarization)
원문의 의미를 이해하여 새로운 문장으로 재작성합니다.

**장점**: 자연스럽고 간결함, 요약 길이 제어 용이
**단점**: 간혹 의미 왜곡 가능성

LLM은 추상 요약에 훨씬 효과적입니다.

### 2. 요약의 핵심 요소

- **길이**: 원문의 10-30% 수준으로 설정
- **스타일**: 비즈니스, 학술, 일상 등 목적에 맞게 조정
- **관점**: 객관적 요약 vs 특정 관점에서의 요약
- **상세도**: 간단 요약 vs 상세 요약

### 3. 요약 품질 평가

요약의 좋은 품질을 판단하는 기준:

- **정확성**: 원문의 주요 정보를 정확히 포함
- **완전성**: 핵심 개념 누락 없음
- **간결성**: 중복 없이 간단명료함
- **자연성**: 문장이 자연스럽고 읽기 쉬움
- **중립성**: 객관적이고 편향 없음

## 실무 활용 예제

### 예제 1: 뉴스 기사 요약

#### 상황
일일 뉴스 50개를 빠르게 파악해야 하는 리서치 팀입니다.

#### 프롬프트

```
당신은 전문 기자입니다. 다음 뉴스 기사를 요약해주세요.

요약 형식:
- 제목: 원문 제목 유지
- 요약 (3-4문장): 객관적이고 간결하게
- 핵심 포인트 (3개 bullet): 가장 중요한 내용
- 출처 영향도: high/medium/low

뉴스 기사:
---
[기사 전문을 여기에 붙여넣기]
---

요약을 한글로 작성해주세요.
```

#### 예상 응답

```
제목: 국내 전기차 판매량, 작년 대비 45% 증가

요약:
한국자동차산업협회 발표에 따르면 2024년 전기차 판매량이 전년 대비
45% 증가했습니다. 이는 정부의 세제 혜택과 충전 인프라 확대에 기인한
것으로 보입니다. 특히 테슬라와 현대자동차가 시장 점유율 상위를
차지했습니다.

핵심 포인트:
• 2024년 전기차 판매량 45% 증가 (작년 대비)
• 정부 세제 혜택 및 충전 인프라 확대가 주요 요인
• 테슬라, 현대자동차가 시장 선도

출처 영향도: HIGH (산업 정책에 직접적 영향)
```

### 예제 2: 회의록 요약 (한국식 형식)

#### 상황
2시간짜리 전략 회의의 내용을 임원진용 요약본으로 만들어야 합니다.

#### 프롬프트

```
당신은 회사의 경영 지원 담당자입니다.

다음 회의록을 한국식 경영진 보고 형식으로 요약해주세요.

요약 구성:
1. 회의 개요 (날짜, 참석자, 의제)
2. 주요 안건 및 논의 내용 (3-5개)
3. 의사결정 사항 (O/X로 표시)
4. 과제 할당 (담당자, 완료 기한)
5. 차기 회의 일정

회의록:
---
[회의록 전문을 여기에 붙여넣기]
---

형식을 깔끔하게 정리하여 보고서 형태로 작성해주세요.
```

#### 예상 응답

```
📋 회의록 요약

【회의 개요】
• 개최일: 2024년 2월 20일 14:00-16:00
• 장소: 3층 회의실 A
• 참석자: CEO, CMO, CFO, 마케팅팀장, 개발팀장
• 주제: Q1 마케팅 전략 수립

【주요 안건 및 결정】

1. SNS 마케팅 예산 증액
   ✓ 결정: 인스타그램 광고 예산 월 3,000만원 → 5,000만원으로 증액
   • 이유: 20-30대 고객층 집중
   • 담당자: 마케팅팀 김영희 부장

2. 제품 론칭 일정
   ✓ 결정: 3월 15일 론칭 확정
   • 기술팀에서 개발 일정 준수 확약
   • 담당자: 개발팀 이순신 팀장

3. 인플루언서 협업
   검토 중: 5-7명 선정 후 차기 회의에서 재논의
   • 담당자: 마케팅팀 박지원 대리

4. 고객 만족도 조사
   ✗ 보류: 외부 용역사 재선정 필요
   • 담당자: 경영지원팀 최민호 대리

【과제 할당】

| 과제 | 담당자 | 기한 |
|------|--------|------|
| SNS 광고 플랜 수립 | 마케팅팀 김영희 | 2/27 |
| 론칭 체크리스트 작성 | 개발팀 이순신 | 2/25 |
| 인플루언서 추천 리스트 | 마케팅팀 박지원 | 3/1 |
| 조사 용역사 재견적 | 경영지원팀 최민호 | 2/28 |

【차기 회의】
• 일정: 2024년 3월 6일 14:00
• 안건: Q1 마케팅 성과 모니터링, 인플루언서 협업 최종 결정
```

### 예제 3: 학술 논문 요약

#### 프롬프트

```
당신은 학술 분야 전문가입니다. 다음 논문의 초록(Abstract)을
한국 대학생이 이해할 수 있도록 요약해주세요.

형식:
• 논문 제목: [원문 제목]
• 핵심 주장: [한 문장으로]
• 연구 방법: [어떻게 연구했는가]
• 주요 발견: [발견한 사실 3-4개]
• 시사점: [실무/학문적 의의]
• 난이도: ⭐⭐☆ (1-5단계)

논문 초록:
---
[논문 초록을 여기에 붙여넣기]
---
```

#### 예상 응답

```
📚 논문 요약

• 논문 제목: "생성형 AI와 대학 교육의 미래"

• 핵심 주장:
  생성형 AI의 등장으로 대학 교육은 지식 전달 중심에서
  비판적 사고와 창의력 중심으로 변환되어야 한다.

• 연구 방법:
  미국 50개 대학의 1,000명 학생을 대상으로
  ChatGPT 사용 경험을 설문 조사

• 주요 발견:
  - 71%의 학생이 보고서 작성에 AI를 활용
  - AI 활용 학생의 성적이 10% 상향 이동
  - 교수는 이를 "학업 부정행위 우려"로 인식 (80%)
  - 학생은 "학습 효율 도구"로 인식 (65%)

• 시사점:
  대학에서는 AI 사용을 금지하기보다 "AI와 협업하는 능력"을
  교과과정에 통합해야 함. 이는 직업 전환기 인재 양성에 필수적.

• 난이도: ⭐⭐⭐ (중상)
```

### 예제 4: 복잡한 기술 문서 요약

#### 프롬프트

```
당신은 기술 문서 전문가입니다. 다음 [기술 사양서/API 문서]를
비기술자도 이해할 수 있는 레벨로 요약해주세요.

요약 방식:
1. 한 문장 설명 (초등학생도 이해 가능)
2. 용어 설명 (어려운 용어 5개)
3. 실제 사용 사례 (2-3개)
4. 주의사항 (2-3개)

문서:
---
[기술 문서를 여기에 붙여넣기]
---
```

#### 예상 응답

```
📖 기술 문서 요약: API 인증 시스템

【한 문장 설명】
"API 인증은 온라인 쇼핑할 때 비밀번호를 입력하듯이,
컴퓨터끼리 통신할 때 자신이 누구인지 증명하는 과정입니다."

【주요 용어】
1. API: 컴퓨터들이 서로 대화하는 "공식 통로"
2. 토큰: 신분증 같은 디지털 증명서
3. OAuth: 페이스북 계정으로 다른 앱 로그인하는 방식
4. 엔드포인트: API를 사용하는 정해진 "주소"
5. 헤더: 편지의 "발신자/수신자 정보"처럼 기본정보

【실제 사용 사례】
- 모바일 앱이 클라우드 서버의 사진을 가져오기
- 전자상거래 사이트가 결제 시스템과 연결하기
- SNS 앱이 친구 목록을 실시간으로 동기화하기

【주의사항】
- 토큰을 절대 타인에게 공개하지 말기 (신용카드처럼)
- 토큰은 만료되므로 정기적으로 갱신하기
- 모든 통신은 암호화해서 진행하기
```

### 예제 5: 다양한 길이의 요약 (스케일링)

#### 프롬프트

```
다음 텍스트의 요약을 3가지 길이로 제공해주세요.

원문:
---
[원문을 여기에 붙여넣기]
---

【One-liner (한 문장, 20단어 이내)】
[가장 짧은 요약]

【Short Summary (단락, 3-5문장)】
[보통 길이 요약]

【Detailed Summary (상세, 10-15문장)】
[긴 요약]
```

#### 예상 응답

```
【One-liner】
"국가 전기차 보조금이 2024년부터 축소되지만, 배터리 기술 발전으로
가격 경쟁력은 여전히 유지될 전망."

【Short Summary】
정부의 전기차 구매 보조금이 2024년부터 단계적으로 축소될 예정입니다.
이에 따라 소비자의 구매 의사가 저하될 우려가 있습니다. 그러나
배터리 원가가 하락하고 기술이 발전함에 따라 전기차 가격 경쟁력은
여전히 유지될 것으로 예상됩니다.

【Detailed Summary】
정부의 전기차 구매 보조금 축소 정책이 업계에 미칠 영향을 분석한
이 보고서에 따르면, 2024년부터 보조금이 단계적으로 감소합니다.
승용차 기준 현재 900만원에서 600만원으로 축소될 예정입니다.
이로 인해 전기차 수요가 감소할 수 있다는 우려가 제기됩니다.
그러나 전문가들은 긍정적으로 평가합니다. 배터리 생산 비용이
연 10% 수준으로 하락하고 있기 때문입니다. LG화학, SK이노베이션,
삼성SDI 등 국내 배터리 제조업체들의 기술 발전으로 생산 원가가
감소하고 있습니다. 따라서 자동차 제조사들이 보조금 축소분을
어느 정도 흡수할 수 있을 것으로 예상됩니다. 결론적으로
정부 보조금 축소는 시장 성장에 일시적 영향을 주겠지만,
장기적으로는 기술 발전으로 인한 가격 경쟁력으로 시장이 지속될
것으로 전망됩니다.
```

## 💡 실전 팁

!!! tip "효과적인 요약 프롬프트"

    1. **명확한 길이 지정**: "3-4문장" 또는 "원문의 20%" 같이 구체적으로

    2. **스타일 명시**: 학술적, 일상적, 비즈니스, 간편식 등 톤 지정

    3. **핵심 우선사항**: "가격 정보는 반드시 포함", "이름은 제외" 등

    4. **출력 형식 지정**: bullet point, table, narrative 등 선택

    5. **언어 레벨 지정**: "고등학생 수준", "전문가용" 등 명시

!!! tip "문제 상황별 해결책"

    **"AI가 내용을 잘못 요약했어요"**
    → 원문의 핵심 포인트를 3-5개 직접 제시한 후 "이 포인트들을 반영해서 다시 요약해주세요"

    **"너무 길어요/너무 짧아요"**
    → "너무 길다"는 주관적. "500자 이내" 같이 정확한 길이 재지정

    **"요약이 너무 일반적이어요"**
    → 원문의 3-5개 핵심 key point를 직접 제공하고 "이것들이 모두 포함되어야 합니다" 강조
