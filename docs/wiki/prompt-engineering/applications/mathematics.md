# 수학 추론과 문제 풀이

LLM의 수학 능력은 뛰어나지만, Chain-of-Thought (CoT) 프롬프팅을 통해 더욱 향상시킬 수 있습니다. 산술, 대수, 기하, 확률 문제 등을 효과적으로 풀 수 있습니다.

## 핵심 개념

### 1. LLM의 수학 능력

**장점**:
- 대수, 기하 개념 이해
- 다단계 문제 해결
- 수학적 증명 작성
- 문제 풀이 과정 설명

**제한사항**:
- 매우 큰 수의 정확한 계산 (100자리 이상)
- 복잡한 통계 계산
- 특정 수치 데이터 암기 오류

### 2. Chain-of-Thought (CoT) 프롬프팅

**기본 원칙**: "단계별로 생각해보세요"

```
× "2x + 3 = 9를 풀어라"
  → 가끔 오류 (x = 3)

○ "2x + 3 = 9를 풀어라. 각 단계를 자세히 설명해주세요."
  → 정확한 풀이 과정과 답변

○ "다음을 단계별로 풀어주세요:
   1단계: 방정식을 정리한다
   2단계: x의 계수로 양변을 나눈다
   3단계: x의 값을 구한다

   2x + 3 = 9"
  → 정확성 95% 이상
```

### 3. 수학 문제 유형별 전략

| 문제 유형 | 효과적인 전략 | 정확도 |
|----------|-------------|--------|
| **산술** | 단계별 계산 | 95%+ |
| **대수** | CoT + 변수 정의 | 90-95% |
| **기하** | 다이어그램 설명 + CoT | 85-90% |
| **확률/통계** | 수식 명시 + 계산 과정 | 80-85% |
| **문제 풀이** | 상황 분석 + 수식 설정 | 85-90% |

## 실무 활용 예제

### 예제 1: 실생활 문제 풀이 (자동차 대출)

#### 프롬프트

```
당신은 수학 튜터입니다. 다음 금융 수학 문제를 풀어주세요.

【문제】
김민수가 새 자동차를 구매하기 위해 은행에서 3,000만원을 차용했습니다.
연이율은 4.5%, 상환 기간은 5년입니다.
매달 얼마씩 상환해야 할까요?

【풀이 요구사항】
1. 주어진 정보 정리
2. 사용할 공식 설명
3. 각 단계별 계산
4. 최종 답변
5. 현실적 해석

풀어주세요.
```

#### 예상 응답

```
【풀이】

1️⃣ 주어진 정보 정리
- 대출금 (원금, PV) = 30,000,000원
- 연이율 (r) = 4.5% = 0.045
- 월이율 (i) = 0.045 / 12 = 0.00375
- 상환 기간 = 5년 = 60개월

2️⃣ 사용 공식: 등비급수를 이용한 월상환금 계산

월상환금 = P × [i(1 + i)^n] / [(1 + i)^n - 1]

여기서:
- P: 대출금 (30,000,000)
- i: 월이율 (0.00375)
- n: 상환 개월 수 (60)

3️⃣ 단계별 계산

Step 1: (1 + i)^n 계산
(1 + 0.00375)^60 = (1.00375)^60 = 1.2462

Step 2: 분자 계산
i × (1 + i)^n = 0.00375 × 1.2462 = 0.004673

Step 3: 분모 계산
(1 + i)^n - 1 = 1.2462 - 1 = 0.2462

Step 4: 월상환금 계산
월상환금 = 30,000,000 × (0.004673 / 0.2462)
         = 30,000,000 × 0.01898
         = 569,400원

4️⃣ 최종 답변
**월 상환액: 약 569,400원**

5️⃣ 현실적 해석
- 총 상환액: 569,400 × 60 = 34,164,000원
- 이자 총액: 34,164,000 - 30,000,000 = 4,164,000원
- 5년 동안 대출금의 약 13.9%에 해당하는 이자 지불

⚠️ 참고: 실제 금융기관은 보험료, 수수료 등이 추가될 수 있습니다.
```

### 예제 2: 기하 문제 (피타고라스 정리 응용)

#### 프롬프트

```
당신은 기하학 전문가입니다.

다음 건축 기하 문제를 풀어주세요.

【문제】
건축가가 직각삼각형 모양의 부지를 설계했습니다.
밑변(b) = 30m, 높이(h) = 40m일 때:

1) 대각선 길이는?
2) 삼각형의 넓이는?
3) 둘레는?

【풀이 방식】
- 다이어그램 설명
- 공식 명시
- 단계별 계산
- 실제 의미 해석

풀어주세요.
```

#### 예상 응답

```
【기하학 풀이】

【다이어그램】
       /|
      / |h=40m
     /  |
    /   |
   /____|
   b=30m

위 직각삼각형에서:
- 밑변: 30m
- 높이: 40m
- 대각선: c = ?

【1. 대각선 길이 (피타고라스 정리)】

공식: c² = a² + b²

계산:
c² = 30² + 40²
c² = 900 + 1,600
c² = 2,500
c = √2,500
c = 50m

✓ 대각선 길이: **50m**

【2. 삼각형 넓이】

공식: 넓이 = (1/2) × 밑변 × 높이

계산:
넓이 = (1/2) × 30 × 40
     = (1/2) × 1,200
     = 600m²

✓ 넓이: **600m²**

【3. 둘레】

공식: 둘레 = a + b + c

계산:
둘레 = 30 + 40 + 50
     = 120m

✓ 둘레: **120m**

【실제 의미】
부지가 30m × 40m의 직각삼각형 모양이라면:
- 한 대각선을 따라 이동할 경우 50m 소요
- 전체 면적은 600m² (축구장의 약 0.7배)
- 펜스를 치려면 120m의 자재 필요
```

### 예제 3: 확률 문제

#### 프롬프트

```
당신은 확률 수학 강사입니다.

다음 확률 문제를 풀어주세요.

【문제】
어떤 온라인 시험에서:
- 합격률: 70%
- 100명 응시

1) 정확히 70명이 합격할 확률?
2) 70명 이상 합격할 확률?
3) 불합격자의 기댓값?

【조건】
- 각 응시자는 독립적
- 이항분포 사용
- 근사값 계산 허용

풀어주세요.
```

#### 예상 응답

```
【확률 문제 풀이】

【주어진 정보】
- n = 100 (시행 횟수)
- p = 0.7 (성공 확률)
- q = 0.3 (실패 확률)

이는 이항분포 B(100, 0.7)를 따릅니다.

【1. 정확히 70명이 합격할 확률】

이항분포 확률 공식:
P(X = 70) = C(100,70) × (0.7)^70 × (0.3)^30

계산이 매우 복잡하므로 정규분포로 근사:

평균: μ = np = 100 × 0.7 = 70
표준편차: σ = √(npq) = √(100 × 0.7 × 0.3) = √21 ≈ 4.58

Z-점수: Z = (70 - 70) / 4.58 = 0

표준정규분포표에서 Z ≈ 0일 때:
P(X = 70) ≈ 0.087 = **약 8.7%**

【2. 70명 이상 합격할 확률】

P(X ≥ 70) = P(Z ≥ 0) = 0.5 = **50%**

이는 직관적으로 이해됩니다:
- 평균이 70명이므로
- 70명 이상일 확률은 정확히 50%

【3. 불합격자의 기댓값】

불합격자 수 = 100 - 합격자
합격자의 기댓값 = 100 × 0.7 = 70명

불합격자의 기댓값 = 100 - 70 = **30명**

또는 직접:
E(불합격자) = n × q = 100 × 0.3 = 30명

【검증】
- 합격자 기댓값: 70명 (70%)
- 불합격자 기댓값: 30명 (30%)
- 합: 70 + 30 = 100명 ✓
```

### 예제 4: 복합 문제 (수열과 급수)

#### 프롬프트

```
당신은 수학 올림피아드 코치입니다.

다음 수열 문제를 풀어주세요.

【문제】
어떤 회사의 월간 판매액이 다음과 같이 증가합니다:
- 1월: 100만원
- 2월: 110만원
- 3월: 121만원
- 4월: 133.1만원

1) 이 수열의 규칙은?
2) 12개월 동안의 총 판매액은?
3) 어느 달에 월 판매액이 250만원을 넘을까?

【풀이 조건】
- 패턴 인식
- 공식 도출
- 계산 및 답변

풀어주세요.
```

#### 예상 응답

```
【수열 문제 풀이】

【1단계: 패턴 인식】

월별 판매액을 보면:
- 1월: 100
- 2월: 110 (= 100 × 1.1)
- 3월: 121 (= 110 × 1.1)
- 4월: 133.1 (= 121 × 1.1)

✓ **등비수열입니다!** (첫항: 100, 공비: 1.1)

일반항: a_n = 100 × (1.1)^(n-1)

【2단계: 12개월 총 판매액】

등비급수의 합 공식:
S_n = a × (r^n - 1) / (r - 1)

여기서:
- a = 100 (첫항)
- r = 1.1 (공비)
- n = 12 (항의 개수)

S_12 = 100 × ((1.1)^12 - 1) / (1.1 - 1)
     = 100 × (3.1384 - 1) / 0.1
     = 100 × 2.1384 / 0.1
     = 100 × 21.384
     = 2,138.4만원

✓ **12개월 총 판매액: 약 2,138만원**

【3단계: 월 판매액이 250만원을 넘는 달】

a_n = 100 × (1.1)^(n-1) > 250

(1.1)^(n-1) > 2.5

양변에 로그를 취하면:
(n-1) × log(1.1) > log(2.5)
(n-1) × 0.0414 > 0.3979
n-1 > 9.62
n > 10.62

따라서 n = 11

확인:
- 10월: 100 × (1.1)^9 = 100 × 2.358 = 235.8만원 (미달)
- 11월: 100 × (1.1)^10 = 100 × 2.594 = 259.4만원 ✓

✓ **11월에 월 판매액이 250만원을 넘습니다**

【최종 정리】
- 수열 유형: 등비수열 (a₁=100, r=1.1)
- 연간 총액: 약 2,138만원
- 250만원 달성: 11월
```

## 💡 실전 팁

!!! tip "수학 문제 풀이 팁"

    1. **단계적 지시 (Step-by-Step)**
       ```
       "다음을 풀어주세요:
        1. 주어진 정보를 정리
        2. 사용할 공식 명시
        3. 각 단계별 계산
        4. 최종 답변"
       ```

    2. **공식 명시**
       ```
       × "y = 2x + 3에서 x가 5일 때 y는?"
       ○ "일차함수 y = 2x + 3에서, x = 5를 대입하여 y의 값을 구하세요"
       ```

    3. **검증 포함**
       ```
       "답을 구한 후 원래 식에 대입하여 검증해주세요"
       ```

    4. **다이어그램 요청**
       ```
       "기하 문제일 때는 먼저 다이어그램을 ASCII art로 표현해주세요"
       ```

    5. **근사값 명시**
       ```
       "답을 정확한 값과 근사값(소수점 이하 2자리) 둘 다 제시해주세요"
       ```

!!! tip "자주 하는 실수 회피"

    ```
    × "이 계산 문제의 답은?" (가끔 오류)
    ○ "이 계산을 단계별로 풀어주세요" (높은 정확도)

    × "확률을 구하세요" (상황 불명확)
    ○ "이항분포를 따를 때 P(X=k)를 구하세요" (명확)

    × "더 빠르게 계산해주세요"
    ○ "빠르기보다 정확성을 우선해주세요" (품질 향상)
    ```
