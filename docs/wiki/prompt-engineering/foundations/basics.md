# 프롬프트 기초

## 프롬프트란 무엇인가?

프롬프트(Prompt)는 사용자가 생성형 AI 모델에게 보내는 입력값 또는 요청입니다. 사람이 다른 사람에게 질문하거나 지시사항을 주는 것처럼, 우리는 프롬프트를 통해 AI 모델에게 원하는 작업을 지시합니다.

**예제:**

```
프롬프트: "서울의 날씨가 어때?"
응답: AI 모델이 서울의 현재 날씨 정보를 제공합니다.
```

프롬프트는 단순한 질문일 수도 있고, 상세한 지시사항일 수도 있습니다. 프롬프트의 품질이 높을수록 더 좋은 결과를 얻을 수 있습니다.

## 프롬프트의 기본 구조

효과적인 프롬프트는 일반적으로 다음과 같은 요소들로 구성됩니다:

### 1. 명확한 지시문
모델이 수행해야 할 작업을 분명하게 설명합니다.

```
"다음 문장을 영어로 번역하세요:"
```

### 2. 맥락 정보
필요한 배경 정보나 상황을 제공합니다.

```
"마케팅 이메일을 위해"
```

### 3. 입력 데이터
실제로 처리할 내용입니다.

```
"안녕하세요. 저는 새로운 제품을 구매했습니다."
```

### 4. 출력 형식 지시
원하는 결과의 형식을 명시합니다.

```
"JSON 형식으로 답변해 주세요."
```

## 기본 프롬프트 형식

### 질문/답변 형식

가장 기본적이고 직관적인 형식입니다.

```
Q: 대한민국의 수도는 어디인가요?
A:
```

AI 모델은 "A:" 이후에 답변을 생성합니다.

**예제:**

```
Q: 2024년 파리 올림픽은 몇 개 국가가 참가했나요?
A: 206개 국가와 지역이 참가했습니다.
```

### 시스템/사용자/어시스턴트 역할

더 구조화된 형식으로, 대부분의 현대적 AI API에서 사용됩니다.

```
System: 당신은 한국사 전문가입니다.
User: 삼국시대에 대해 설명해 주세요.
Assistant: 삼국시대는 고구려, 백제, 신라가 한반도를 통일할 때까지 경쟁한 시대입니다...
```

**각 역할의 의미:**

- **System**: 모델의 역할이나 행동 방식을 정의합니다.
- **User**: 사용자가 보내는 메시지나 질문입니다.
- **Assistant**: 모델이 생성한 응답입니다.

## 간단한 예제들

### 예제 1: 텍스트 요약

**프롬프트:**
```
다음 텍스트를 한 문장으로 요약해 주세요.

텍스트: 인공지능은 우리의 일상 생활에 점점 더 많은 영향을 미치고 있습니다. 
스마트폰의 음성 인식, 추천 시스템, 자율주행차 등 다양한 분야에서 
인공지능이 활용되고 있으며, 앞으로 이러한 추세는 계속될 것으로 예상됩니다.

요약:
```

**예상 응답:**
```
인공지능은 스마트폰, 추천 시스템, 자율주행차 등 다양한 분야에서 
우리의 일상에 영향을 미치고 있으며, 그 활용이 계속 증가할 것으로 예상됩니다.
```

### 예제 2: 질문-답변

**프롬프트:**
```
Q: 생성형 AI란 무엇인가요?
A:
```

**예상 응답:**
```
생성형 AI는 텍스트, 이미지, 코드 등 새로운 콘텐츠를 생성할 수 있는 
인공지능 시스템입니다. 대규모 데이터를 학습하여 사용자의 요청에 따라 
창의적이고 유용한 결과물을 만들어냅니다.
```

### 예제 3: 역할 정의

**프롬프트:**
```
System: 당신은 친절한 영어 교사입니다. 학생들의 실수를 지적할 때는 
격려하면서 올바른 표현을 알려주세요.

User: I goes to school every day.
Assistant:
```

**예상 응답:**
```
좋은 시도입니다! 주어의 형태에 따라 동사의 형태도 달라져야 해요.
"I"는 단수형 주어이므로 "goes" 대신 "go"를 사용합니다.

올바른 표현: "I go to school every day."

자세히 설명하면, 3인칭 단수("he", "she", "it")일 때만 동사에 "s"가 붙습니다.
```

## 좋은 프롬프트의 특징

✅ **명확함** - 모델이 수행할 작업이 분명합니다.  
✅ **구체적** - 일반적이지 않고 구체적인 요청입니다.  
✅ **완전함** - 필요한 모든 정보를 포함합니다.  
✅ **간결함** - 불필요한 말이 없습니다.

## 프롬프트 작성 시 피해야 할 것들

❌ **모호함** - "이것을 좋게 만들어 줘"  
❌ **불완전함** - 필요한 정보 없음  
❌ **과도한 길이** - 불필요하게 긴 설명  
❌ **모순** - 서로 다른 요청을 동시에 함

## 💡 실전 팁

!!! tip "프롬프트 작성 팁"

    1. **명확한 동작 동사 사용**: "~해 주세요", "~해 주시겠습니까?"보다는 "분석해", "작성해", "설명해" 등의 명령형 동사를 사용하면 더 정확한 결과를 얻을 수 있습니다.

    2. **예제 포함하기**: 원하는 형식을 명확히 하기 위해 예제를 보여주는 것이 효과적입니다.

    3. **한 번에 하나씩**: 복잡한 요청은 여러 개의 작은 프롬프트로 나누는 것이 더 좋은 결과를 만듭니다.

    4. **프롬프트 테스트**: 같은 프롬프트를 여러 번 시도해서 일관성 있는 결과가 나오는지 확인하세요.

## 프롬프트 개선 예제

### 나쁜 프롬프트
```
좋은 이력서 만들어 줘
```

### 개선된 프롬프트
```
System: 당신은 채용 담당자입니다.

User: 소프트웨어 엔지니어 직무에 지원할 이력서를 작성해 주세요.
다음 정보를 포함해 주세요:
- 기본 정보: 이름, 연락처, 이메일
- 학력: 대학교, 전공, 졸업 연도
- 경력: 회사명, 직책, 담당 업무 (3개 예시)
- 기술 스택: Python, JavaScript, React, Django
- 자격증: 정보처리기사

형식: 마크다운으로 작성해 주세요.
```

## 📝 핵심 정리

- **프롬프트**는 AI 모델에게 보내는 입력값 또는 요청입니다.
- 효과적인 프롬프트는 **명확성**, **구체성**, **완전성**, **간결성**을 갖춥니다.
- 기본 형식으로는 **질문/답변 형식**과 **시스템/사용자/어시스턴트 형식**이 있습니다.
- 좋은 결과를 위해서는 **명확한 지시문**, **충분한 맥락**, **입력 데이터**, **출력 형식 지시**가 필요합니다.
- 초보자일 때는 **단순하게 시작**하고 **반복적으로 개선**하는 것이 중요합니다.
