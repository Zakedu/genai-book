# 프롬프트의 요소들

프롬프트 엔지니어링에 대한 더 많은 예시와 응용을 다루면서, 특정 요소들이 프롬프트를 구성한다는 것을 알게 될 것입니다.

프롬프트는 다음 요소 중 일부 또는 전체를 포함할 수 있습니다:

**명령어(Instruction)** - 모델이 수행하기를 원하는 구체적인 작업이나 명령어

**맥락(Context)** - 외부 정보나 추가적인 맥락으로, 모델이 더 나은 응답을 생성하도록 유도할 수 있음

**입력 데이터(Input Data)** - 응답을 찾고자 하는 입력 또는 질문

**출력 지표(Output Indicator)** - 원하는 출력의 유형이나 형식

다음은 텍스트 분류 작업을 수행하는 프롬프트 요소의 예시입니다:

**프롬프트:**
```
Classify the text into neutral, negative, or positive

Text: I think the food was okay.

Sentiment:
```

위의 프롬프트 예시에서 명령어는 "Classify the text into neutral, negative, or positive" 부분에 해당합니다. 입력 데이터는 "I think the food was okay." 부분이고, 출력 지표는 "Sentiment:" 입니다. 이 기본 예시는 맥락을 사용하지 않지만, 프롬프트의 일부로 추가적인 맥락을 제공할 수도 있습니다. 예를 들어, 이 텍스트 분류 프롬프트의 맥락은 모델이 작업을 더 잘 이해하고 기대하는 출력 유형을 안내하는 데 도움이 되는 추가 예시로 제공될 수 있습니다.

프롬프트에 네 가지 요소를 모두 포함할 필요는 없으며, 형식은 작업에 따라 달라집니다. 다음 가이드에서 더 구체적인 예시를 다룰 것입니다.

---

## 핵심 개념

- 명령어: 수행할 작업을 명확히 정의
- 맥락: 모델의 이해와 응답을 개선하기 위한 배경 정보
- 입력 데이터: 처리할 구체적인 텍스트나 정보
- 출력 지표: 원하는 형식과 유형 명시
- 선택적 구성: 모든 요소가 항상 필요한 것은 아님

## 왜 중요한가

프롬프트 요소들의 체계적인 이해는 효과적인 지시문을 작성하는 토대입니다. 각 요소의 역할을 이해하면, 다양한 작업에 맞게 프롬프트를 조정할 수 있으며, 모델의 성능을 최적화할 수 있습니다. 이는 프롬프트 엔지니어링의 기초적이면서도 필수적인 개념입니다.

## 시험 포인트

- 각 프롬프트 요소의 기능과 역할
- 작업에 따른 요소 조합 방식
- 명령어의 명확성이 결과에 미치는 영향
- 맥락 제공의 효과
- 출력 형식 지표의 구체성
