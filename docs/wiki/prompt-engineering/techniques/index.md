# 기법(Techniques)

핵심 프롬프팅 기법을 실습 예제와 함께 학습합니다.

## 목차

### 기본 기법

- **[영샷 프롬프팅](zero-shot.md)** - 예시 없이 명령어만으로 작업을 수행. 명령어 튜닝과 RLHF의 역할 설명

- **[퓨샷 프롬프팅](few-shot.md)** - 몇 가지 예시를 통해 모델을 유도. 맥락 내 학습의 실제 적용

- **[사고의 연쇄 프롬프팅](chain-of-thought.md)** - 중간 추론 단계를 명시하여 복잡한 문제 해결. 영샷 CoT와 자동 CoT 포함

### 고급 기법

- **[자기 일관성](self-consistency.md)** - 여러 추론 경로를 탐색하여 합의 기반의 최종 답변 도출

- **[ReAct 프롬프팅](react.md)** - 추론(Reasoning)과 행동(Action)을 결합하여 도구 사용과 외부 정보 활용

- **[프롬프트 체이닝](prompt-chaining.md)** - 복잡한 작업을 순차적인 여러 프롬프트로 분해

## 기법별 적합한 작업

| 기법 | 주요 적합 작업 | 복잡도 | 비용 |
|-----|-------------|-------|-----|
| 영샷 | 간단한 명령어 기반 작업 | 낮음 | 낮음 |
| 퓨샷 | 패턴 학습이 필요한 작업 | 낮음-중간 | 낮음 |
| CoT | 수학, 논리 추론 | 중간 | 중간 |
| 자기 일관성 | 높은 정확성이 필요한 작업 | 높음 | 높음 |
| ReAct | 도구 사용이 필요한 작업 | 높음 | 높음 |
| 체이닝 | 다단계 복잡한 작업 | 높음 | 높음 |

## 기법 선택 가이드

### 작업이 간단할 때
→ **영샷** 사용: 비용이 낮고 빠름

### 특정 패턴을 학습시켜야 할 때
→ **퓨샷** 사용: 형식이나 스타일 지정 가능

### 복잡한 추론이 필요할 때
→ **사고의 연쇄(CoT)** 사용: 단계별 사고 과정 강조

### 매우 높은 정확성이 필요할 때
→ **자기 일관성** 사용: 여러 경로 탐색 (비용 증가)

### 외부 도구나 정보가 필요할 때
→ **ReAct** 사용: 도구 호출 능력 활용

### 매우 복잡한 다단계 작업일 때
→ **프롬프트 체이닝** 사용: 단계별로 분해하여 처리

## 기법의 조합

여러 기법을 결합하여 더 강력한 시스템을 구축할 수 있습니다:

- **CoT + 자기 일관성**: "단계별로 생각하고" + "여러 경로 탐색"
- **퓨샷 + CoT**: 예시 제공 + 추론 단계 강조
- **체이닝 + ReAct**: 순차 처리 + 도구 사용
- **체이닝 + CoT**: 각 단계에서 사고의 연쇄 적용

## 실무 팁

### 비용 관리
- 먼저 영샷으로 시도
- 필요하면 퓨샷 추가
- 필요시에만 고급 기법(자기 일관성, ReAct)

### 성능 최적화
- 각 기법의 파라미터 튜닝 (온도, 샘플링)
- 프롬프트 포맷 테스트
- 모델 크기와 기법의 적합성 검증

### 모니터링
- 각 단계의 출력 검증
- 오류 패턴 분석
- 정기적인 성능 평가
