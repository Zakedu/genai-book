# 프롬프트 체이닝(Prompt Chaining)

## 개요

프롬프트 체이닝은 복잡한 작업을 여러 개의 순차적 프롬프트로 분해하는 기법입니다. 각 프롬프트의 출력이 다음 프롬프트의 입력으로 사용되어, 단계별로 작업을 진행합니다.

## 기본 개념

### 문제: 너무 복잡한 단일 프롬프트

복잡한 작업을 한 번에 하나의 거대한 프롬프트로 해결하려고 하면, 모델의 성능이 저하될 수 있습니다.

### 해결책: 체이닝

작업을 작은 단위로 나누고, 각 단위의 출력을 다음 입력으로 사용합니다.

## 프롬프트 체이닝의 예시

### 예시 1: 뉴스 기사 분석

**단계 1: 기사 요약**
```
프롬프트: 다음 기사를 3-4문장으로 요약하세요.
기사: [긴 뉴스 기사 텍스트]

출력: [요약된 텍스트]
```

**단계 2: 감정 분석**
```
프롬프트: 다음 텍스트의 전체 감정을 분석하세요.
텍스트: [단계 1의 출력]

출력: [긍정/부정/중립]
```

**단계 3: 주요 주제 추출**
```
프롬프트: 다음 요약에서 3-5개의 주요 주제를 추출하세요.
요약: [단계 1의 출력]

출력: [주제 목록]
```

**단계 4: 최종 보고서 작성**
```
프롬프트: 다음 정보를 바탕으로 최종 분석 보고서를 작성하세요.
요약: [단계 1의 출력]
감정: [단계 2의 출력]
주제: [단계 3의 출력]

출력: [최종 보고서]
```

### 예시 2: 코드 리뷰

**단계 1: 코드 분석**
```
프롬프트: 다음 코드의 목적과 주요 기능을 설명하세요.
코드: [코드 텍스트]

출력: [분석]
```

**단계 2: 버그 찾기**
```
프롬프트: 다음 코드의 잠재적 버그나 문제점을 찾으세요.
코드: [코드 텍스트]
분석: [단계 1의 출력]

출력: [문제점 목록]
```

**단계 3: 개선 제안**
```
프롬프트: 다음 코드를 개선하기 위한 제안을 하세요.
코드: [코드 텍스트]
문제점: [단계 2의 출력]

출력: [개선 제안]
```

## 프롬프트 체이닝의 장점

1. **복잡성 관리**: 큰 작업을 작은 단위로 분해
2. **명확성**: 각 단계가 명확한 목표를 가짐
3. **재사용성**: 각 단계를 다른 작업에 재사용 가능
4. **디버깅**: 어느 단계에서 문제가 발생했는지 파악 용이
5. **성능 향상**: 각 단계를 최적화할 수 있음

## 프롬프트 체이닝의 한계

1. **비용 증가**: 여러 번의 모델 호출
2. **지연시간**: 순차 처리로 인한 속도 저하
3. **오류 누적**: 각 단계의 오류가 다음 단계에 영향
4. **복잡한 관리**: 여러 프롬프트 유지 필요

## 구현 패턴

### 패턴 1: 선형 체이닝
```
Prompt1 → Output1 → Prompt2 → Output2 → Prompt3 → Final Output
```

### 패턴 2: 분기 체이닝
```
                → Prompt2A → Output2A
Prompt1 → Output1 ⤷ Prompt2B → Output2B ⤳ Prompt3 → Final Output
                → Prompt2C → Output2C
```

### 패턴 3: 피드백 루프
```
Prompt1 → Output1 → Prompt2 → Output2 ⤳
                        ↓
                    Prompt3 (검증)
                        ↓
                    Output3 ✓
```

## 실무 적용 가이드

### 언제 체이닝을 사용할 것인가?

**효과적한 경우:**
- 여러 단계의 처리가 필요한 경우
- 각 단계의 결과를 검증해야 할 때
- 복잡한 분석 또는 변환 작업
- 품질이 중요한 경우

**부적절한 경우:**
- 단순한 질의응답
- 실시간 처리 필요
- 빠른 응답 필요

## 오류 처리 전략

### 중간 검증 추가

각 단계 후 결과의 품질을 검증하는 프롬프트를 추가할 수 있습니다:

```
Prompt1 → Output1 → [검증 프롬프트] → 품질 확인
                                    ↓
                              (조건부) Prompt1 재실행
                                    ↓
                                 Prompt2로 진행
```

### 대체 경로 설정

결과가 품질 기준을 만족하지 않으면 다른 접근 방식 사용

## 프롬프트 체이닝과 RAG(Retrieval-Augmented Generation)

프롬프트 체이닝은 RAG 시스템과 결합할 수 있습니다:

1. **검색**: 관련 문서 검색
2. **추출**: 검색된 문서에서 정보 추출
3. **합성**: 추출된 정보를 바탕으로 최종 답변 생성

## 핵심 개념

- 작업 분해: 복잡한 작업을 작은 단계로 분리
- 순차 처리: 각 단계의 출력이 다음 입력
- 데이터 흐름: 각 단계 간의 정보 흐름 관리
- 오류 처리: 중간 검증과 대체 경로
- 유지보수성: 모듈식 설계로 수정과 개선 용이

## 왜 중요한가

프롬프트 체이닝은 복잡한 작업을 체계적으로 구성하는 방법을 제공합니다. 이는 프로덕션 환경에서 신뢰할 수 있는 LLM 시스템을 구축하는 핵심 기법입니다.
