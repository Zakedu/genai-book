# 자기 일관성(Self-Consistency)

## 개요

자기 일관성은 사고의 연쇄 프롬프팅을 개선하는 기법으로, 여러 추론 경로를 탐색하여 가장 일관된 답변을 선택합니다. 단순히 모델의 첫 번째 출력을 사용하는 대신, 여러 번 샘플링하여 다양한 추론 경로를 얻고, 이들 사이에서 합의(Majority Vote)를 통해 최종 답변을 결정합니다.

## 기본 원리

### 기본 CoT의 문제

기존 사고의 연쇄 프롬프팅에서는 모델의 첫 번째 추론 경로만 사용됩니다. 그러나 모델이 때때로 잘못된 추론 경로를 선택할 수 있습니다.

### 자기 일관성의 해결책

자기 일관성은 다음과 같이 작동합니다:

1. **여러 샘플링**: 동일한 문제에 대해 모델을 여러 번 실행 (예: 5, 10, 20회)
2. **다양한 경로**: 각 실행마다 다른 추론 경로가 생성됨
3. **투표(Voting)**: 모든 샘플의 최종 답변을 수집
4. **합의**: 가장 많은 표를 받은 답변을 선택

## 자기 일관성의 예시

### 산술 추론 문제

**문제:** 15, 32, 5, 13, 82, 7, 1 그룹에서 홀수의 합이 짝수인가?

**1차 실행 (CoT):**
```
홀수: 15, 5, 13, 7, 1
합: 41
41은 홀수입니다. → 답변: False
```

**2차 실행 (CoT):**
```
홀수: 15, 5, 13, 7, 1
홀수는 다섯 개입니다.
홀수개 + 홀수개 + 홀수개 + 홀수개 + 홀수개 = 홀수
→ 답변: False
```

**3차 실행 (다른 접근):**
```
홀수 개수: 5개 (홀수)
홀수의 합은 홀수개 × 홀수 = 홀수
→ 답변: False
```

**최종 결과**: 3개 모두 False → **답변: False** ✓

## 자기 일관성의 장점

1. **정확성 향상**: 여러 경로를 탐색하여 올바른 답변 확률 증가
2. **견고성**: 모델의 일회성 오류 감소
3. **신뢰도**: 여러 경로가 같은 답변일 때 신뢰도 향상
4. **추론 다양성**: 다양한 사고 방식 포착

## 자기 일관성의 한계

1. **비용 증가**: 여러 번 샘플링으로 인한 API 호출 증가
2. **속도 저하**: 순차적 처리 필요
3. **메모리**: 여러 추론 결과 저장 필요
4. **모든 작업에 적합하지 않음**: 단순한 사실 기반 답변은 도움이 될 수 있음

## 구현 가이드

### Python 예시 구조

```python
# 1. 여러 번 샘플링
responses = []
for i in range(sample_count):  # 예: 5-10회
    response = model.generate_with_cot(prompt)
    responses.append(extract_answer(response))

# 2. 투표
from collections import Counter
answer_counts = Counter(responses)
final_answer = answer_counts.most_common(1)[0][0]
```

### 최적화 전략

1. **표본 크기**: 5~10회 샘플링이 일반적으로 효율적
2. **온도 조정**: 온도를 높여 다양한 경로 생성
3. **병렬 처리**: 동시 요청으로 속도 개선
4. **비용 관리**: 중요한 작업에만 사용

## 자기 일관성과 다른 기법의 결합

자기 일관성은 다른 프롬프팅 기법과 결합할 수 있습니다:

- **CoT + 자기 일관성**: 가장 일반적인 조합
- **ReAct + 자기 일관성**: 여러 행동 경로 탐색
- **퓨샷 + 자기 일관성**: 예시와 함께 여러 경로
