# 영샷 프롬프팅(Zero-Shot Prompting)

## 개요

오늘날의 대형 언어 모델(LLM)인 GPT-3.5 Turbo, GPT-4, Claude 3 등은 명령어를 따르도록 조정되었으며 대량의 데이터로 학습되었습니다. 대규모 학습으로 인해 이러한 모델은 "영샷(Zero-shot)" 방식으로 일부 작업을 수행할 수 있습니다.

영샷 프롬프팅은 모델과 상호작용할 때 사용하는 프롬프트에 예시나 시연이 포함되지 않음을 의미합니다. 영샷 프롬프트는 추가 예시를 제공하지 않고 모델에게 작업을 직접 지시합니다.

## 영샷 프롬프팅의 예시

### 텍스트 분류

**프롬프트:**
```
Classify the text into neutral, negative or positive.

Text: I think the vacation is okay.
Sentiment:
```

**출력:**
```
Neutral
```

위의 프롬프트에서 모델에 분류 예시를 제공하지 않았습니다. LLM은 이미 "감정(Sentiment)"이라는 개념을 이해합니다. 이것이 영샷 능력이 작동하는 방식입니다.

## 명령어 튜닝의 역할

명령어 튜닝은 명령어를 통해 설명된 데이터셋에서 모델을 미세 조정하는 개념입니다. 이는 영샷 학습을 개선하는 것으로 입증되었습니다.

또한 강화학습과 인간 피드백(RLHF: Reinforcement Learning from Human Feedback)은 대규모로 명령어 튜닝을 확장하기 위해 채택되었습니다. 이러한 최근의 발전은 ChatGPT와 같은 모델의 힘을 제공합니다.

## 언제 영샷 프롬프팅을 사용할 것인가?

영샷 프롬프팅은 작업이 간단하고, 모델이 작업을 충분히 이해할 수 있을 때 효과적입니다. 영샷이 작동하지 않으면, 프롬프트에 시연이나 예시를 포함하는 것이 권장되며, 이는 퓨샷 프롬프팅으로 이어집니다.

## 실무 적용

영샷 프롬프팅은 다음과 같은 작업에 효과적입니다:

- 간단한 명령어 기반 작업
- 모델이 이미 학습한 개념
- 예시가 명확할 필요가 없는 직관적 작업
- 빠른 프로토타이핑 및 테스트

더 복잡한 작업이나 특정 스타일이 필요한 경우에는 퓨샷 프롬프팅을 사용해야 합니다.

---

## 핵심 개념

- 영샷 능력: 예시 없이 새로운 작업을 수행할 수 있는 능력
- 명령어 튜닝: 모델이 명령어를 따르도록 학습되는 과정
- RLHF: 인간 피드백을 통한 모델 개선
- 작업의 복잡도: 영샷이 작동하는 조건
- 모델 크기: 더 큰 모델일수록 영샷 능력이 우수함

## 왜 중요한가

영샷 프롬프팅은 LLM의 강력한 특징이며, 신속한 프로토타이핑을 가능하게 합니다. 명령어 튜닝과 RLHF의 발전으로 모던 LLM은 매우 복잡한 작업도 예시 없이 수행할 수 있게 되었습니다. 이는 LLM 시스템 설계의 기초가 되는 중요한 개념입니다.

## 시험 포인트

- 영샷과 퓨샷의 명확한 구분
- 영샷이 효과적인 작업의 특징
- 명령어 튜닝의 중요성
- RLHF가 영샷 능력에 미치는 영향
- 영샷이 작동하지 않을 때의 대안
