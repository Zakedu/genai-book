# LLM을 활용한 추론 (Reasoning with LLMs)

## 개요

이 섹션에는 LLM의 추론 기능을 테스트하기 위한 프롬프트 모음이 포함되어 있습니다.

## 추론 기법

- [간접 추론](/prompt-engineering/03-reasoning/indirect-reasoning)
- [물리적 추론](/prompt-engineering/03-reasoning/physical-reasoning)

---

## 핵심 개념

- 간접 추론: 대우(contrapositive)와 모순의 논리를 사용한 추론 방법
- 물리적 추론: 객체 간의 상호작용과 안정성을 고려한 공간적 추론
- 증명법: 직접 증명, 귀류법, 대우를 이용한 증명 등 다양한 증명 기법
- 체계적 사고: 문제를 단계별로 분석하고 모든 가능성 검토

## 왜 중요한가

LLM의 추론 능력을 이해하는 것은 논리적 사고, 수학적 증명, 물리적 문제 해결 등 고차원적 작업에 LLM을 적용하는 데 필수적입니다. 다양한 추론 기법을 테스트하고 개선함으로써 LLM 기반 시스템의 신뢰성과 정확성을 향상시킬 수 있습니다.

## 시험 포인트

- 다양한 추론 방식(직접, 간접, 귀류법)의 효과 비교
- LLM이 복잡한 논리 구조를 이해하고 따르는 능력
- 물리적 상식과 공간적 관계에 대한 이해도
- 증명 구조와 논리적 일관성 검증
