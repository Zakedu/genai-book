# LLM을 위한 검색 증강 생성 (RAG for LLMs)

## 개요

LLM 작업 시 도메인 지식 격차, 사실성 문제, 환각(hallucination)과 같은 많은 과제가 있습니다. 검색 증강 생성(RAG)은 데이터베이스와 같은 외부 지식으로 LLM을 증강하여 이러한 문제 중 일부를 완화하는 솔루션을 제공합니다. RAG는 특히 지식 집약적 시나리오나 계속 업데이트되는 지식이 필요한 도메인 특화 애플리케이션에서 유용합니다. RAG의 주요 장점은 다른 접근 방식과 달리 LLM을 작업별 애플리케이션을 위해 재훈련할 필요가 없다는 것입니다. RAG는 대화형 에이전트와의 응용으로 최근에 인기를 얻었습니다.

## RAG 프레임워크 소개

<!-- 이미지: RAG 프레임워크 -->

[여기서 더 잘 소개된 바와 같이](https://www.promptingguide.ai/techniques/rag), RAG는 다음과 같이 정의할 수 있습니다:

> RAG는 입력을 받아 소스(예: Wikipedia)로부터 관련/지원 문서의 집합을 검색합니다. 문서들은 원래 입력 프롬프트와 함께 컨텍스트로 연결되고 최종 출력을 생성하는 텍스트 생성기에 공급됩니다. 이것은 사실이 시간에 따라 변할 수 있는 상황에서 RAG를 적응형으로 만듭니다. 이는 LLM의 파라미터 지식이 정적이기 때문에 매우 유용합니다. RAG를 통해 언어 모델은 재훈련을 우회하고 최신 정보에 접근하여 검색 기반 생성을 통해 신뢰할 수 있는 출력을 생성할 수 있습니다.

간단히 말해서, RAG에서 검색된 증거는 LLM의 응답의 정확성, 제어 가능성, 그리고 관련성을 향상시키는 방법이 될 수 있습니다. RAG가 환각 문제를 완화하거나 고도로 진화하는 환경에서 문제를 해결할 때 성능을 높이는 데 도움이 될 수 있다는 것이 바로 이 이유입니다.

RAG도 사전 훈련 방법의 최적화를 포함했지만, 현재 접근 방식은 대체로 [ChatGPT](https://www.promptingguide.ai/models/chatgpt)와 [Mixtral](https://www.promptingguide.ai/models/mixtral)과 같은 강력한 미세 조정 모델과 RAG의 강점을 결합하는 방향으로 전환했습니다. 아래 차트는 RAG 관련 연구의 진화를 보여줍니다:

다양한 단계/구성 요소를 다음과 같이 설명할 수 있습니다:

- **입력**: LLM 시스템이 응답하는 질문을 입력이라고 합니다. RAG를 사용하지 않으면 LLM이 질문에 직접 응답합니다.
- **인덱싱**: RAG를 사용하면 먼저 관련 문서 세트를 청크로 분할하고, 청크의 임베딩을 생성하고, 벡터 저장소에 인덱싱합니다. 추론 시 쿼리도 유사한 방식으로 임베딩됩니다.
- **검색**: 쿼리와 인덱싱된 벡터를 비교하여 관련 문서를 얻습니다. "관련 문서"로도 표시됩니다.
- **생성**: 관련 문서를 원래 프롬프트와 함께 추가 컨텍스트로 결합합니다. 그 다음 결합된 텍스트와 프롬프트를 모델에 전달하여 응답을 생성하고 최종 출력으로 사용자에게 제공됩니다.

제공된 예에서 모델을 직접 사용하면 현재 이벤트에 대한 지식 부족으로 인해 질문에 응답하지 못합니다. 반면 RAG를 사용하면 시스템은 모델이 질문에 적절히 답변하기 위해 필요한 관련 정보를 가져올 수 있습니다.

## 핵심 개념

- **RAG 파이프라인**: 인덱싱 → 검색 → 생성의 3단계 프로세스
- **임베딩 기반 검색**: 의미적 유사성을 기반으로 한 관련 문서 검색
- **컨텍스트 증강**: 검색된 문서를 프롬프트에 추가하여 생성 품질 향상
- **동적 지식 업데이트**: 파라미터 업데이트 없이 새로운 정보 통합
- **벡터 저장소**: 임베딩 인덱싱과 빠른 검색을 위한 기반 구조

## 왜 중요한가

RAG는 LLM의 고정된 지식 기반이라는 근본적인 제한을 극복합니다. 외부 지식 소스와의 동적 연결을 통해 LLM은 최신 정보, 도메인 특화 지식, 그리고 사용자 정의 데이터에 접근할 수 있게 됩니다. 이는 지속적으로 변화하는 정보가 중요한 분야에서 신뢰성 있는 AI 시스템을 구축하는 데 필수적입니다.

## 시험 포인트

- RAG의 각 단계(인덱싱, 검색, 생성)의 성능 평가
- 검색 관련성과 생성 품질의 상관관계
- 다양한 임베딩 모델과 검색 알고리즘의 성능 비교
- 컨텍스트 길이 제한과 정보 손실의 처리
- 실시간 데이터 업데이트와 일관성 유지
- 검색 정확도(precision)와 재현율(recall)의 균형
