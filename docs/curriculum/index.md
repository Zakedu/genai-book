# 학습 로드맵

<p class="apex-eyebrow">CURRICULUM · 트랙별 학습 경로</p>

생성형 AI 개념 120개를 **학습 위계(선행 관계)**로 정렬한 지도입니다. 상단에서 **트랙**을 고르고 개념을 클릭하면, 그 개념을 배우기 위해 **먼저 알아야 할 것(필수·심화)**과 **다음에 배울 것**이 트랙에 맞게 표시됩니다.

<div id="learning-path-app"></div>

!!! note "관계는 3-AI 교차검증으로"
    선행 관계와 강도(필수 vs 심화), 트랙 분류는 Claude가 추출하고 Codex가 적대적으로 반박·검증한 결과입니다.
