*[Reinforcement Learning]: 강화학습 — 보상과 벌칙을 통해 AI가 최적의 행동을 학습하는 방식
*[RAG]: 검색 증강 생성 — 외부 데이터베이스에서 관련 정보를 검색하여 AI 응답에 활용하는 기술
*[Overfitting]: 과적합 — AI가 학습 데이터에만 지나치게 맞춰져 새로운 데이터에서 성능이 떨어지는 현상
*[Grounding]: 그라운딩 — AI 응답을 실제 데이터나 출처에 기반하도록 하는 기법
*[Noise]: 노이즈 — 데이터에 포함된 불필요하거나 오류가 있는 정보
*[LLM]: 대규모 언어 모델 — 방대한 텍스트 데이터로 학습된 AI 모델 (예: GPT-5.4, Claude 4.6, Gemini 3.1 P
*[Data Augmentation]: 데이터 증강 — 기존 데이터를 변형하여 학습 데이터를 늘리는 기법
*[Decoder]: 디코더 — 트랜스포머 구조에서 출력을 생성하는 부분
*[Multimodal]: 멀티모달 — 텍스트, 이미지, 오디오 등 여러 형태의 데이터를 함께 처리하는 능력
*[Meta Prompt]: 메타 프롬프트 — AI의 전반적인 행동 방식을 지정하는 시스템 수준의 프롬프트
*[Vector]: 벡터 — 텍스트나 이미지를 숫자 배열로 변환한 것
*[Vector Database]: 벡터 데이터베이스 — 벡터화된 데이터를 저장하고 유사도 검색을 수행하는 데이터베이스
*[Baseline]: 베이스라인 — 비교 기준이 되는 기본 성능 수치
*[Generative AI]: 생성형 AI — 텍스트, 이미지, 코드 등 새로운 콘텐츠를 생성하는 AI
*[Self-Attention]: 셀프 어텐션 — 입력 시퀀스 내에서 각 요소가 다른 요소들과의 관계를 계산하는 메커니즘
*[System Prompt]: 시스템 프롬프트 — AI의 역할, 성격, 제약 조건을 정의하는 프롬프트
*[Agent]: 에이전트 — 자율적으로 작업을 수행하고 결정을 내리는 AI 시스템
*[Inline Visualization]: 인라인 시각화 — 대화 내에서 직접 차트, 다이어그램 등을 생성하는 기능 (예: Claude의 인라인 차트/다이어그램)
*[Epoch]: 에폭 — 전체 학습 데이터를 한 번 완전히 학습하는 주기
*[Encoder]: 엔코더 — 트랜스포머 구조에서 입력을 이해하고 표현하는 부분
*[Embedding]: 임베딩 — 텍스트, 이미지 등을 고정 길이의 숫자 벡터로 변환하는 과정
*[Alignment]: 정렬 — AI가 인간의 의도와 가치에 맞게 행동하도록 하는 것
*[Zero-shot]: 제로샷 — 예시 없이 AI가 직접 작업을 수행하는 방식
*[Inference]: 추론 — 학습된 AI 모델이 새로운 입력에 대해 결과를 생성하는 과정
*[Cowork]: 코워크 — Anthropic Claude의 지속적 에이전트 스레드(persistent agent thread) 기능. 
*[Context Window]: 컨텍스트 윈도우 — AI가 한 번에 처리할 수 있는 텍스트의 최대 길이 (토큰 수로 측정)
*[Token]: 토큰 — AI가 텍스트를 처리하는 기본 단위 (단어, 부분 단어, 문자 등)
*[Tokenizer]: 토크나이저 — 텍스트를 토큰으로 분할하는 도구
*[Transformer]: 트랜스포머 — 현대 LLM의 기반이 되는 신경망 아키텍처
*[Parameter]: 파라미터 — AI 모델 내부의 학습 가능한 가중치 (GPT-4는 약 1.8조 개)
*[Fine-tuning]: 파인튜닝 — 사전 학습된 모델을 특정 작업에 맞게 추가 학습시키는 과정
*[Prompt]: 프롬프트 — AI에게 전달하는 입력 텍스트 또는 지시문
*[Prompt Engineering]: 프롬프트 엔지니어링 — 원하는 결과를 얻기 위해 프롬프트를 최적화하는 기술
*[Few-shot]: 퓨샷 — 몇 가지 예시를 제공하여 AI의 응답 패턴을 유도하는 기법
*[Hyperparameter]: 하이퍼파라미터 — 모델 학습 과정을 제어하는 설정값 (학습률, 배치 크기 등)
*[Hallucination]: 할루시네이션/환각 — AI가 사실이 아닌 정보를 마치 사실인 것처럼 생성하는 현상
*[Artificial General Intelligence]: AGI — 인간 수준의 범용 인공지능
*[AGI]: AGI — 인간 수준의 범용 인공지능
*[Application Programming Interface]: API — AI 모델을 외부 프로그램에서 호출할 수 있게 하는 인터페이스
*[CoT]: Chain of Thought — 단계별 추론을 유도하는 프롬프팅 기법
*[Chain of Thought]: Chain of Thought — 단계별 추론을 유도하는 프롬프팅 기법
*[Generative Pre-trained Transformer]: GPT — OpenAI가 개발한 생성형 언어 모델 시리즈
*[GPT]: GPT — OpenAI가 개발한 생성형 언어 모델 시리즈
*[Reinforcement Learning from Human Feedback]: RLHF — 인간 피드백을 통해 AI를 학습시키는 방법
